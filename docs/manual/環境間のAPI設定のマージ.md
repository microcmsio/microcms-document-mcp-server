# 環境間のAPI設定のマージ

環境間のAPI設定のマージは、開発・検証環境で確認した設定を本番環境へ反映したり、本番環境で変更した設定を開発・検証環境へ反映したりする際に利用できる機能です。  
環境間でAPI設定の差分を比較し、反映したいAPIを選択することで、APIの基本情報・スキーマやカスタムフィールドの設定をまとめて反映できます。  
マージは、別環境から本番環境への反映だけでなく、本番環境から別環境へ、別環境同士の反映にも対応しています。

環境間のAPI設定のマージはBusinessプラン、Enterpriseプランでご利用いただける機能です。 プランごとの利用条件については、[料金プラン](https://microcms.io/pricing)をご確認ください。

マージを実行すると、マージ先のAPI設定が変更されます。差分の内容によっては、APIやフィールドの新規作成・変更・削除が発生します。マージ元とマージ先、差分内容を十分に確認してから実行してください。マージによって失われたデータは、誤って削除した場合でも、弊社での復旧対応は承っておりません。

マージの流れ
------

### 1\. マージ先の環境を開く

設定を反映したい環境を開き、環境設定から［API設定のマージ］を選択します。  
現在表示している環境がマージ先になります。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/482cbd5e3fe04095b03b76448211e495/CleanShot%202026-10-02%20at%2014.56.00.png)

### 2\. マージ元の環境を選択する

マージ元の環境を選択します。  
例：ステージング環境の設定を本番環境へ反映する場合

*   マージ元：ステージング環境
*   マージ先：本番環境（現在表示している環境になります）

  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/1ad026a104b040d2a620d8a22f37ab91/CleanShot%202026-10-02%20at%2010.09.12.png)

### 3\. 差分を確認する

［差分を確認する］ボタンをクリックすると、環境間で差分のあるAPIが表示されます。左側の一覧では、差分の種類ごとにAPIを確認できます。

*   変更されるAPI
*   新規作成されるAPI
*   削除されるAPI

APIを選択すると、差分が表示されます。以下の内容を確認し、マージしたいAPIのチェックボックスにチェックを入れてください。

*   APIの基本情報
*   APIスキーマ
*   フィールドの追加・変更・削除
*   変更前と変更後の値

![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/9d1959566896402bab4002790c17c9a0/CleanShot%202026-10-02%20at%2010.12.15.png)

マージ元に存在せず、マージ先にのみ存在するAPIやフィールドは、削除対象になる場合があります。詳しくは「マージ元に存在しないAPIやフィールドがある場合」をご確認ください。

### 4\. マージ内容を確認してマージを実行する

［マージ内容を確認する］ボタンをクリックし、選択したAPIについて以下を確認します。

*   マージ可否
    *   コンテンツ参照フィールド・複数コンテンツ参照フィールドで設定している参照先のAPIが存在しない場合や、削除対象のリスト形式のAPIにコンテンツが存在する場合は、マージを実行できません
*   マージ対象のAPI
*   処理の順序
*   各APIで実行される処理
    *   基本情報の追加・変更
    *   スキーマの追加・変更
    *   APIやフィールドの削除・再作成
*   追加料金の有無

内容に問題がないことを確認したら、画面下部の［マージを実行する］をクリックします。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/654f037a04d445cb969ed7f271fde273/CleanShot%202026-10-02%20at%2015.04.33.png)

### 5\. マージ結果を確認する

マージが開始されると、処理順序に沿ってAPIごとの処理状況が表示されます。すべての処理が「成功」となり、「マージ完了」と表示されたらマージは完了です。  
処理に失敗した場合、後続のAPIの処理はスキップされます。対応方法は「[その他の注意事項](#h2e13b14e16)」をご確認ください。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/efd580a746474ba7a3d77a31488943a4/CleanShot%202026-10-02%20at%2015.10.48.png)

料金
--

マージによって新しいAPIが作成され、契約プランのAPI数上限を超える場合、追加料金が発生することがあります。

*   マージ実行前に、新規作成されるAPI数と料金が表示されます
*   実際の課金は、新規APIが作成されるタイミングで発生します
*   不要な追加課金を避けるため、可能な限りAPIの削除を優先して処理します。ただし、参照関係などの制約により、一時的にAPI数が契約プランの上限を超える場合があります。超過する時間は通常、数秒程度ですが、処理内容や状況によって異なります。短時間の超過であっても追加料金が発生する場合があり、その料金は次回の請求金額に反映されます。詳しくは、ヘルプサイトの「[月の途中で追加メンバーや追加APIの数量を変更した場合、請求額はどのように計上されますか？](https://help.microcms.io/ja/knowledge/next-billing-date)」をご確認ください。

  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/610e919545654b1f84e67a4710aaab0d/CleanShot%202026-10-02%20at%2015.04.332.png)

必要な権限
-----

複数環境機能で作成した環境では権限管理を利用できないため、マージの実行に必要な権限は、マージ元・マージ先に本番環境が含まれるかどうかによって異なります。  
マージに関係する権限は、次の2つです。

### **環境への読み取り権限**

*   別環境では、環境への読み取り権限があれば、その環境のAPIを操作できます

### **本番環境のAPI権限**

*   本番環境では、APIごとの権限が適用されます
*   マージ元では、APIの読み取り権限が必要です
*   マージ先では、すべてのAPIに対する読み取り・作成・編集・削除権限が必要です

基本的には、**マージ元では読み取り、マージ先では変更操作に必要な権限**が求められます。

環境への読み取り権限が「URLを知っている環境のみ」のロールでは、マージ元の環境を一覧から選択できません。そのため、本番環境から現在表示している環境へのマージのみ実行できます。

マージされないデータ・設定項目
---------------

マージの対象は、API設定とカスタムフィールドの設定のみです。コンテンツやメディアは、マージ元からコピーされません。

### フィールドの初期値

以下のフィールドは、フィールド設定自体はマージ対象ですが、設定された初期値はマージされません。マージ先の既存のフィールドでは、初期値がそのまま残ります。新しく作成されたフィールドでは、マージ後にマージ先の環境で設定してください。

*   リッチエディタ
*   画像
*   複数画像
*   ファイル
*   コンテンツ参照
*   複数コンテンツ参照

### 設定項目

以下の設定は、マージの対象外です。

*   コンテンツID設定
*   カスタムステータス
*   画面プレビュー設定
*   Webhook設定
*   APIのIP制限

これらの設定は、マージ元とマージ先で異なっていても差分として検知されないため、マージ先の設定がそのまま残ります。マージによって新しく作成されたAPIでは未設定の状態になるため、必要に応じてマージ先の環境で設定してください。

注意事項
----

### 削除・再作成が発生する可能性がある変更

変更内容によっては、マージ先で既存の設定を更新するのではなく、対象を削除したり、削除してから新しく作成したりする場合があります。

#### APIのエンドポイントを変更する場合

APIのエンドポイントを変更すると、マージ先では既存APIの更新ではなく、削除と再作成として処理されます。  
ただし、リスト形式のAPIで、削除対象のAPIにコンテンツが存在する場合は、APIを削除できないため、マージを実行できません。

オブジェクト形式のAPIは、コンテンツが存在していても削除と再作成が実行されます。その場合、既存のコンテンツは失われます。

また、削除対象のAPIが他のAPIから参照されている場合は、参照元のAPIもあわせてマージ対象に含めるか、先にマージする必要があります。その場合、参照元のAPIのコンテンツ参照フィールド・複数コンテンツ参照フィールドは削除と再作成が行われ、フィールドに設定されていた値は削除されます。  
マージ内容の確認画面で、マージ可否と注意事項を確認してください。

**推奨する対応**

*   **開発の初期段階など、マージ先のコンテンツや参照フィールドの値が失われても問題ない場合**：そのままマージを実行してください。削除と再作成によって反映されます。リスト形式のAPIにコンテンツがある場合は、コンテンツを削除してから実行してください
*   **運用中の環境など、マージ先のコンテンツや参照フィールドの値を残したい場合**：マージを実行する前に、マージ先のAPIのエンドポイントをマージ元と同じ値に手動で変更してください。同じAPIとして判定され、更新として処理されます

マージ先のAPIのエンドポイントを変更すると、Webhookの実行や、APIを利用しているサイト・外部サービスとの連携などに影響する場合があります。影響範囲を確認してから変更してください。

#### フィールドIDやカスタムフィールドIDを変更する場合

環境の作成後に、それぞれの環境で個別に追加したフィールドやカスタムフィールドは、マージ元とマージ先でIDが異なると、同じものと判定されません。その場合、マージ先では既存のフィールドの更新ではなく、削除と再作成として処理されます。コンテンツは削除されませんが、フィールドに設定されていた値は削除されます。  
なお、環境の作成時から存在するフィールドやカスタムフィールドは、IDを変更しても同じものとして判定されます。  
マージ内容の確認画面で、マージ可否と注意事項を確認してください。

**推奨する対応**

*   **開発の初期段階など、マージ先のフィールドの値が失われても問題ない場合**：そのままマージを実行してください。削除と再作成によって反映されます
*   **運用中の環境など、マージ先のフィールドの値を残したい場合**：マージを実行する前に、マージ先のフィールドIDやカスタムフィールドIDをマージ元と同じ値に手動で変更してください。同じものとして判定され、更新として処理されます

マージ先のフィールドIDやカスタムフィールドIDを変更すると、Webhookの実行や、APIを利用しているサイト・外部サービスとの連携などに影響する場合があります。影響範囲を確認してから変更してください。

#### マージ元に存在しないAPIやフィールドがある場合

マージでは、マージ元のAPI設定を基準にマージ先の設定を更新します。そのため、マージ元に存在せず、マージ先にのみ存在するAPIやフィールドは削除対象になります。例えば、マージ先の環境で独自に追加したフィールドは、マージ元に存在しないため削除されます。  
削除対象のAPIやフィールドにコンテンツが設定されている場合、その値は失われる可能性があります。マージ先のAPIやフィールドを残したい場合は、差分確認画面で削除対象を確認し、対象のAPIをマージ対象から外してください。

### その他の注意事項

*   マージ後に元に戻す機能はありません
*   マージの途中でAPIの処理に失敗した場合、後続のAPIの処理はスキップされます。失敗前に反映済みの変更は自動では元に戻らないため、最新の差分を確認し、対象APIを選択し直してから再度マージしてください
*   差分確認後に環境の設定が変更された場合、最新の設定を再取得して確認し直す必要が生じたり、エラーが発生したりすることがあります
*   差分の確認からマージの完了までは、1つのマージとして扱われます。同じマージ先では、マージを同時に1つしか行えません。ほかのメンバーがマージの途中の場合、管理画面を開くと新しいマージは開始されず、そのマージの現在のステップが表示されます。内容を確認してから操作してください
*   マージ処理の完了後も、検索インデックスの更新などの後処理が続く場合があります。画面上の完了表示と、後処理の完了タイミングは異なることがあります
