# 画面プレビュー

画面プレビューは、管理画面から登録したコンテンツを、公開前にウェブサイトにて確認するための機能です。  

プレビューの仕組み
=========

前提として、microCMSはヘッドレスCMSと呼ばれる見た目を持たないCMSであるため、従来型のCMSとはプレビューの仕組みが根本的に異なります。  
  
プレビューを実施するためには、フロントエンド側でmicroCMSから下書き状態のコンテンツを取得し、レンダリングする仕組みを実装する必要があります。  
そのためには、コンテンツを一意に特定するための`コンテンツID`や、下書き状態のコンテンツを取得するための`draftKey`を、URLとしてフロントエンド側に連携する必要があります。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/92686b08054f4d2db561c8069e7f654e/preview1.jpg)  
  
microCMSでは、管理画面のコンテンツ詳細画面から、プレビュー用の動的なURLを設定する処理を、画面プレビュー機能として提供しています。このドキュメントでは、その設定方法について記載します。  

画面プレビューの設定方法
============

1：任意のAPIを選択します。  
2：「API設定」を選択します。  
3：「画面プレビュー」を選択します。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/19a04b6b7e124bd38edc223d2bc87800/preview02.png)  
  
4：「遷移先URL」欄に連携したいURLを設定し、「変更する」をクリックします。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/4bdd3dee46084907bbf8951a6a66327d/preview03.png)  
  
URLに以下のプレースホルダーを含めると、画面プレビューの実行時に、プレビュー対象のコンテンツに応じた値に置き換わります。

*   `{CONTENT_ID}`：コンテンツID
*   `{DRAFT_KEY}`：draftKey
*   `{FIELD:フィールドID}`：指定したフィールドの値

**フィールドの値をURLに含める場合**  
`{FIELD:フィールドID}`には、以下のフィールドを指定できます。フィールドIDは、大文字・小文字を区別して指定してください。

*   テキストフィールド
*   数字フィールド
*   セレクトフィールド（単一選択のみ）
*   コンテンツ参照フィールド（参照先コンテンツのコンテンツIDのみ）

たとえば、フィールドIDが `slug` のテキストフィールドの値をURLに含める場合は、`{FIELD:slug}` と記述します。  
例：`https://example.com/{FIELD:slug}/draft?id={CONTENT_ID}&draftKey={DRAFT_KEY}`  
  
**コンテンツ参照フィールドを指定する場合**  
コンテンツ参照フィールドでは、フィールドIDの後ろに `.id` を付けることで、参照先コンテンツのコンテンツIDをURLに含められます。  
たとえば、フィールドIDが `category` の場合は、`{FIELD:category.id}` と記述します。  
例：`https://example.com/{FIELD:category.id}/draft?id={CONTENT_ID}&draftKey={DRAFT_KEY}`  
コンテンツID以外のフィールド値や、複数コンテンツ参照フィールドは指定できません。  
  
設定後、コンテンツ詳細画面の［画面プレビュー］ボタンをクリックすると、URL内のプレースホルダーが対象コンテンツの値に置き換わり、そのURLへ遷移します。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/d2257723e10e43cba9e990e591ce0343/CleanShot%202026-11-06%20at%2016.02.22.png)  
  
フロントエンド側では、この値をURLより取得することで、microCMSのAPIにアクセスしてデータを取得することが可能となります。
