# レビュー

2026/11/10より順次リリース予定の[「レビュー機能の承認と公開の分離」のリリース](https://blog.microcms.io/review-approval-publish-flow-change)が反映されたドキュメントとなります。

コンテンツの公開／公開予約、公開終了／公開終了予約の前に、メンバーに内容のレビューを依頼できます。  
作成したレビューは、レビュアーに指定されたメンバーの承認を経て公開・公開終了(予約を含む)操作ができます。

*   レビューはすべてのプランでご利用いただけます。
*   人間のメンバーによるレビューに加えて、AIがコンテンツの品質確認をサポートする「AIレビュー」機能を提供しています。AIレビューの設定方法や使い方については、[AIレビュー](/manual/ai-review)のマニュアルをご覧ください。

レビューの流れ
=======

レビューは、次の流れで進めます。

1.  コンテンツの編集画面からレビューを申請します
2.  レビュアーを指定し、レビュアーはコンテンツの内容や差分の確認、コメントなどを通じてレビューをします
3.  いずれか1人のレビュアーが承認すると、レビューが「反映待ち」になります
    1.  レビューを承認しただけでは、コンテンツの公開・公開終了(予約を含む)の確定はされません
4.  公開・公開終了(予約を含む)操作を行います

レビューのステータス
----------

ステータス

説明

申請中

レビューが申請され、承認を待っている状態です。

反映待ち

必要な承認数(1)を満たし、公開・公開終了(予約を含む)の反映を待っている状態です。

終了

公開・公開終了(予約を含む)を反映した、またはレビューを中止した状態です。

予約を反映した場合、レビューはその時点で「終了」になります。コンテンツの公開・公開終了は、予約した日時に実行されます。

レビューを申請する
=========

コンテンツの編集画面で［レビュー申請］をクリックします。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/439706749e5a481b8ea00f811bfbe926/CleanShot%202026-11-04%20at%2018.03.27.png)  
  
レビュー作成画面で、タイトルと説明を入力します。タイトルは必須です。確認してほしい箇所や変更の目的を説明に記載すると、レビュアーが内容を把握しやすくなります。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/da4409c4ccb449e189dc9428bfd6df7c/CleanShot%202026-11-04%20at%2018.05.28.png)  
  
入力後、［申請する］をクリックするとレビュー詳細画面に移動します。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/f83ad37ecbcb4fcb8e23e097ccd0f0e2/CleanShot%202026-11-04%20at%2018.14.52.png)

スケジュールが設定されたコンテンツは、原則としてレビューを申請できません。

ただし、「公開中かつ下書き中」で公開終了予約のみ設定されている場合は、下書きの公開レビューを申請できます。

公開終了したコンテンツをレビュー申請したい場合は、一度コンテンツを下書きに戻すと申請が可能になります。

レビュアーを指定する
==========

レビュー詳細画面の「レビュアー」から、レビューを依頼するメンバーを指定します。メンバー名で検索でき、最大10人まで指定できます。レビュー申請者自身をレビュアーに指定することもできます。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/04d8984831f448d788258ff48cbcb258/CleanShot%202026-11-04%20at%2018.26.49.png)  
  
各メンバーの承認状況は、「未承認」「承認済み」の表示で確認できます。承認済みのメンバーは、レビュアーから外せません。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/58f14ccbcc684825b4b8c7859b1360bd/CleanShot%202026-11-04%20at%2022.58.22.png)

*   レビュアーの候補は、レビューを依頼するメンバーの「メンバーの読み取り権限」の範囲で表示されます。また対象のレビューを閲覧する権限がないメンバーは、候補に表示されません。
*   レビュアーには、承認権限がないメンバーも指定できます。ただし、実際にレビューを承認するには、レビュー申請の編集権限「承認・編集」が必要です。

AIレビューを利用する
-----------

管理者ロールを持つメンバーは、レビュー画面の［レビュー設定］からAIレビュアーを管理できます。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/e4967d5568cc4ab1b4d90b7d5bb631b7/CleanShot%202026-11-05%20at%2000.27.23.png)  
  
AIレビュアーを利用すると、コンテンツについてのフィードバックをコメントで受け取れます。  
AIレビューの結果は、メンバーによる承認数には含まれません。公開・公開終了に進むには、メンバーによる承認が必要です。  
設定方法や詳しい使い方は、[AIレビュー](https://document.microcms.io/manual/ai-review)をご覧ください。

内容を確認する
=======

コンテンツの差分を確認する
-------------

公開レビューが「申請中」の場合は、「変更差分」タブから、公開中の内容と最新の下書きの差分を確認できます。公開中の内容がない場合は、空の内容と下書きを比較します。「反映待ち」「終了」では、このタブは表示されません。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/e027352a6cf341d39dabd00c5bf566c1/CleanShot%202026-11-04%20at%2023.04.01.png)  
  
レビュー中にコンテンツが更新された場合は、レビュータブの［コンテンツ更新：v○→v○］から、その更新前後の差分も確認できます。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/84f55e54399b4581bcc01377fdc74a30/CleanShot%202026-11-04%20at%2023.08.23.png)

*   空の値の判定については、厳密にはデータが異なる場合にも、差分無しとして判定されることがあります。APIレスポンスに差分が無いことは、必ずしも保証されません。

コメントする
------

レビュー詳細画面のコメント欄で、修正の依頼や確認結果を共有できます。  
コメントの投稿・削除など、利用できる操作はロールの権限によって異なります。  
AIレビューのフィードバックも、このコメント欄に表示されます。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/402cf8cd1117409c80f0bfb2a3e842b6/CleanShot%202026-11-05%20at%2000.33.11.png)

レビューを承認する
=========

レビュアーに指定されたメンバーは、内容を確認したうえで問題がなければ、［承認する］をクリックします。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/e5d0b3a797a44c3bb76094a981dcf8dd/CleanShot%202026-11-04%20at%2023.12.19.png)  
  
現在、必要な承認数は1人です。複数のレビュアーを指定した場合も、いずれか1人が承認すると、「1/1人 承認済み」となり、レビューは「反映待ち」になります。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/ae723f647a774efb910ec3c1cc935290/CleanShot%202026-11-04%20at%2023.13.59.png)

*   ［承認する］をクリックするには、レビュー申請の編集権限「承認・編集」が必要です。承認済みのコンテンツの公開・公開終了（予約を含む）の権限は必要ありません。

承認後にコンテンツを修正したい場合
-----------------

「反映待ち」のコンテンツは「ロック中」になり、編集できません。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/575522c22e134233955df8bbff6596b4/CleanShot%202026-11-04%20at%2023.16.46.png)  
  
コンテンツには、レビューの種類に応じて「公開反映待ち」または「終了反映待ち」のラベルが表示されます。  
承認後に修正が必要になった場合は、レビューを中止してからコンテンツを編集し、新たにレビューを申請してください。

承認されたコンテンツを公開・公開終了(予約を含む)する
===========================

公開・公開終了する
---------

レビューが「反映待ち」になると、公開・公開終了ができます。  
レビュー詳細画面で、申請内容に応じたボタンをクリックしてください。  
実行後、レビューは「終了」になります。

公開・公開終了予約する
-----------

レビュー詳細画面で、公開予約日時や公開終了予約日時を設定できます。  
レビュー詳細画面の「公開予約日時」または「公開終了予約日時」を開き、日時を入力し、［設定］をクリックします。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/1869488517ee4a84a4247142b1b331a3/CleanShot%202026-11-04%20at%2023.26.10.png)

日時の設定やレビューの承認だけでは、予約は確定しません。予約日時より前に公開・公開終了予約操作を完了してください。  
公開・公開終了予約をすると、レビューは「終了」になります。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/88b6a7ff115a458387ff56b9cb43507a/CleanShot%202026-11-04%20at%2023.22.10.png)

*   レビュー詳細画面から公開・公開終了(予約を含む)を実行するには以下の権限が必要です
    *   公開・公開予約：承認済みのコンテンツを公開／公開予約
    *   公開終了・公開終了予約：承認済みのコンテンツを公開終了／公開終了予約
*   公開・公開終了(予約を含む)を実行するメンバーは、レビュアー以外のメンバーが実行することもできます

レビューを中止する
=========

公開を見送る場合や、承認後にコンテンツを修正したい場合は、レビュー詳細画面の［レビューを中止］をクリックします。  
確認画面で［中止する］をクリックすると、コンテンツに反映せずにレビューを「終了」にします。「申請中」「反映待ち」のどちらの状態でも中止できます。  
中止したレビューを再開することはできません。再びレビューする場合は、コンテンツの編集画面から新たにレビュー申請してください。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/98e62b08d5db4536a820e874abe88e1c/CleanShot%202026-11-04%20at%2023.28.51.png)

*   申請者・レビュアーに限らず、対象レビューに対する「編集」または「承認・編集」の権限があるメンバーが中止できます

権限を設定する
=======

レビューの承認と、承認されたコンテンツの公開・公開終了(予約を含む)は、それぞれ別の権限で管理します。  
レビュー詳細画面で操作するには、対象のレビューを閲覧できる必要があります。

操作

主に必要な権限

レビューを申請する

レビュー申請の作成権限

申請内容を編集する・コメントする・レビューを中止する

レビュー申請の編集権限内の「編集」または「承認・編集」

コメントを削除する（自分・他のメンバーのコメント）

レビュー申請の編集権限「承認・編集」

レビューを承認する

レビュー申請の編集権限「承認・編集」

承認後に公開・公開予約する

コンテンツの編集権限内の「承認済みのコンテンツを公開 / 公開予約」

承認後に公開終了・公開終了予約する

コンテンツの編集権限内の「承認済みのコンテンツを公開終了 / 公開終了予約」

レビューを承認するには、必要な権限に加えて、レビュアーに指定されている必要があります。承認後の公開・公開終了には、対象コンテンツの読み取り権限も必要です。  
例えば、次のように権限を設定すると、承認と公開の担当を分けられます。

*   **承認担当者：** レビュー申請の「承認・編集」を付与し、レビュアーに指定します。
*   **公開担当者：** 承認済みコンテンツの公開・公開終了(予約を含む)に必要な権限を付与します。レビュアーへの指定は不要です。

設定方法は、[ロール（管理画面の権限管理）](https://document.microcms.io/manual/roles)をご覧ください。
