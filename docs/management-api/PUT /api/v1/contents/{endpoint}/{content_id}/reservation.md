# PUT /api/v1/contents/{endpoint}/{content_id}/reservation

コンテンツの公開開始、公開終了予約ができるAPIです。  
設定されている予約を解除することもできます。

リクエストヘッダー
=========

X-MICROCMS-API-KEY
------------------

マネジメントAPIのリクエストの際に必要な認証キーです。  
マネジメントAPIのデフォルト権限で「コンテンツのスケジュール設定を変更」を有効にして、リクエストヘッダーに含めて送信してください。  
  
![](https://images.microcms-assets.io/assets/d6af1616730544a596d299c20834f460/bad7b55fd70044fbb54352645e4949d5/put-contents-reservation-management.png)

X-MICROCMS-API-KEYが判別できると、第三者による不正なコンテンツの操作が可能となります。お取り扱いには十分ご注意ください。詳細は「[APIキー（APIの認証と権限管理）](https://document.microcms.io/content-api/x-microcms-api-key)」をご覧ください。

Content-Type
------------

送信するデータの形式を指定します。  
microCMSではJSON形式のデータのみ扱っているため、 `application/json` と指定してください。  

リクエストボディ
========

publishTime(公開時刻)とstopTime(終了時刻)を指定してください。  

    // 公開時刻と終了時刻どちらも設定する場合
    // ※既存の公開開始・終了の設定は上書きされます
    { "publishTime": "2026-01-13T06:31:24.668Z", "stopTime": "2026-01-14T06:31:24.668Z" }
    
    // 公開時刻のみを設定する場合
    // ※既存の公開終了の設定は解除されます
    { "publishTime": "2026-01-13T06:31:24.668Z" }
    
    // 停止時刻のみを設定する場合
    // ※既存の公開開始の設定は解除されます
    { "stopTime": "2026-01-14T06:31:24.668Z" }
    
    // 既存の公開開始・終了のスケジュール設定を解除する場合
    {}

  

時刻フォーマット
--------

ISO 8601 形式の日時文字列で指定します。  
次のいずれかの形式を受け付けます。

*   UTC（Z 終端）
    *   例: `2026-01-14T06:31:24.668Z`
*   UTC（Z なし）
    *   例: `2026-01-14T06:31:24.668`
    *   `Z` がない場合は UTC として解釈されます（例の時刻は `2026-01-14T06:31:24.668Z` と同義です）
*   タイムゾーン（オフセット）付き
    *   例: `2026-01-14T15:31:24.668+09:00`
    *   オフセットを解釈し、UTC に変換して登録されます（上の例は `2026-01-14T06:31:24.668Z` として扱われます）

注意事項
----

*   `null` / `""` はエラーになります。
*   既存の公開開始/公開終了の設定がある場合は上書きされます。
*   リクエストボディに片方だけを指定した場合は、もう片方のスケジュール設定は解除されます。
*   空のJSONオブジェクト（`{}`）を送信すると、既存の公開開始と公開終了のスケジュール設定が解除されます。

レスポンス
=====

ステータスコード
--------

正常に更新できた場合は `200` レスポンスが返却されます。

レスポンスボディ
--------

正常に更新できた場合は、以下のようなレスポンスが返却されます。

    { "id": "some_content_id" }

エラーレスポンス
========

「[マネジメントAPIのエラーレスポンス](/management-api/management-api-error-response)」を参照ください。
